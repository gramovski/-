# Научен статус / Scientific status

Updated: 2026-10-12. Concept author: Hristo Georgiev Gramovski.

## Български

- ORP/Eh динамиката и MMII са обект на изследване; прогнозна способност не е установена.
- Хипотезите за глобален метаболитен резонанс, ензимна памет и следпиково време до земетресение изискват независими измервания и проверки.
- Ранните твърдения за Ip, „терминална фаза“, магнитуд и непосредствено събитие в Svartsengi не са подкрепени с възпроизводим отчет в това хранилище и не се представят като потвърдени.
- Историческият Argus код използва произволно зададени коефициенти и примерни входове. Не изчислява MMII, не е калибриран към магнитуд и не е система за ранно предупреждение.
- В работните бележки по проекта е отбелязана корекция на Grimsel теста от 26.09.2026: резултатът p=0.0189 е отменен заради производни през голямата пауза Aug-2015 → Feb-2016. Това е бележка за отменен анализ, не ново независимо преизчисление тук.
- Числените архивни тестове ще се включват само с прочетени източници, данни, код и описание на ограниченията. Настоящата актуализация не извършва нов сеизмологичен тест.

Предишният README е запазен в [историята на GitHub](https://github.com/gramovski/-/blob/dcba7571780c333aa6e68854040ddf69de424058/README.md). Съдържанието там е историческо и включва непотвърдени твърдения.

## English

ORP/Eh dynamics and MMII remain research subjects; predictive capability is unestablished. Global metabolic resonance, enzyme memory, and post-peak timing require independent measurements and validation.

Historical Ip thresholds, “terminal phase” claims, magnitude estimates, and imminent Svartsengi forecasts have no reproducible supporting report in this repository. They must not be treated as confirmed findings.

Legacy Argus uses arbitrary coefficients and example inputs. It does not calculate MMII and has no validated magnitude calibration or early-warning capability.

Project working notes record a Grimsel correction dated 2026-09-26: p=0.0189 was withdrawn because derivatives crossed the Aug-2015 to Feb-2016 sampling gap. This documents a withdrawn analysis; this repository update does not independently recompute it.

Numerical archive findings should be published with inspected sources, data, code, and limitations. No new seismological test was performed in this update. The previous README remains in GitHub history as historical, unvalidated material.
