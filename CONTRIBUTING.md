# Принос / Contributing

Автор на концепцията / Concept author: Христо Георгиев Грамовски — Hristo Georgiev Gramovski.

Предложенията и критичните проверки могат да се подават чрез GitHub Issues или Pull Requests. Посочвайте източника на данните, условията за използване, единиците, калибрацията, часовата зона, пропуските, метода, кода и ограниченията. Запазвайте отрицателните резултати и авторската атрибуция. Не представяйте хипотеза или статистическа асоциация като доказана прогноза.

Submit proposals and critical checks through GitHub Issues or Pull Requests. Include provenance, reuse terms, units, calibration, time zone, gaps, methods, code, and limitations. Preserve negative findings and author attribution. Distinguish hypotheses and statistical associations from validated predictions.

Do not upload credentials, private data, or datasets without redistribution rights.
